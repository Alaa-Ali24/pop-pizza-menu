# POP Pizza digitalt menukort

Dette er en gratis statisk menu-side, der kan hostes uden database eller backend.

## Filer

- `index.html` er selve siden.
- `styles.css` styrer designet.
- `script.js` indeholder menuen, priserne og kategorierne.
- `pizza-hero.png` er billedet øverst på siden.
- `pop-logo.png` er det lille billede/logo øverst på siden.
- `pop-pizza-menukort.pdf` er original PDF som backup-link.

## Gratis hosting

De letteste gratis muligheder er:

- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel Hobby

Når siden er uploadet og du har fået et link, kan QR-koden laves til det link. Hvis du senere ændrer menuen på samme link, kan den samme QR-kode blive siddende.

Et eget domæne som `poppizza.dk` koster normalt penge, men selve menu-siden kan godt ligge gratis på en adresse fra hosting-tjenesten.
